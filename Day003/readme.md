# Day 3 - Word Frequency Analyzer
# Objective
Build a Python program that counts the frequency of each word in a sentence while learning how dictionaries work.


## Concepts Learned & Used
- String Manipulation
- Lists
-Tupple
-Set
- Dictionary
- Loops
- Conditional Statements


##  Problem Statement

Create a program that:

- Accepts a sentence from the user.
- Ignores uppercase and lowercase differences.
- Removes punctuation.
- Counts the occurrence of every word.
- Displays the frequency of each word.
- Finds the most frequent word.



## Sample Input-AI, ai is Amazing. AI!


##  Sample Output


ai : 3
is : 1
amazing : 1
