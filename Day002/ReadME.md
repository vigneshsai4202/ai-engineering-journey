# Day 2

## Why Python?

Coming from Java, I wanted to understand why Python has become the standard language for AI development.

### My Key observations

- Python has a simpler syntax.
- Most AI frameworks are written for Python first.
- It has a huge ecosystem (PyTorch, TensorFlow, LangChain, FastAPI).
- Rapid prototyping is much faster.

Today My goal wasn't mastering Python—it was understanding why it's the foundation of modern AI development.
