What is a Prompt?

A prompt is the input we give to an AI model to tell it what we want. It can be a simple question, a detailed instruction, or even a conversation. The quality of the prompt often decides the quality of the response.

Instruction vs Context

A good prompt usually has two parts:

Instruction

The instruction tells the AI what task to perform.

Example:

Summarize the following article in five bullet points.

Context

Context provides background information so the AI understands the situation better.

Example:

The article is written for beginners who are learning Artificial Intelligence.

Together

Instruction:

Write a professional email.

Context:

I am applying for a Java Developer internship as a final-year engineering student.

The instruction defines the task, while the context helps the AI produce a more relevant response.
System vs User vs AI Messages

Modern AI chat applications use different types of messages to guide the conversation.

System Message

A system message sets the overall behavior of the AI. It usually contains rules that remain active throughout the conversation.

Example:

You are a helpful programming tutor who explains concepts in simple language.

User Message

A user message contains the request or question asked by the user.

Example:

Explain the difference between ArrayList and LinkedList.

AI Message

An AI message is the response generated by the model.

Example:

ArrayList stores elements in a dynamic array, while LinkedList stores elements as connected nodes.
Zero-Shot vs Few-Shot Prompting
Zero-Shot Prompting

In zero-shot prompting, the AI is asked to perform a task without seeing any examples.

Example:

Translate "Good Morning" into French.

The AI already understands translation and produces the answer directly.
Few-Shot Prompting

Few-shot prompting provides one or more examples before asking the actual question. These examples help the AI understand the expected format or style.

Example:

Positive review → Positive

Negative review → Negative

"The movie was excellent."

The AI learns from the examples and classifies the new review correctly.

Role Prompting

Role prompting means assigning the AI a specific role before asking a question. This helps the model respond from a particular perspective.

Examples:

Act as a Java interviewer.
Giving the AI a role often produces responses that are more focused and realistic.
Constraints in Prompting

Constraints are additional rules that limit how the AI should respond. They make the output more predictable.

Examples of constraints:

Answer in less than 100 words.
Use simple English.
Structured Output

Structured output means asking the AI to return information in a fixed format instead of free-flowing text.

Instead of receiving a long paragraph, the response follows a predefined structure that is easier for programs to read and process.

Example (JSON):

{
  "name": "Java",
  "type": "Programming Language",
  "released": 1995
}
Structured output is commonly used when AI responses need to be consumed by applications or APIs.
Why JSON is Useful for Java Applications

JSON (JavaScript Object Notation) is one of the most widely used data formats for communication between applications.

In Java applications, JSON is useful because:

It is lightweight and easy to read.
It is supported by libraries such as Jackson and Gson.
It can be easily converted into Java objects (POJOs).
It is commonly used in REST APIs.
It allows different systems to exchange data in a standard format.

Example JSON:

{
  "employeeId": 101,
  "name": "Sai Vignesh",
  "department": "Engineering"
}

In Java, this JSON can be converted directly into an object using libraries like Jackson or Gson, making data handling simple and efficient.
Prompt JSON vs Schema-Validated Structured Output

Although both use JSON, they serve different purposes.

Prompt JSON

In prompt JSON, we simply ask the AI to respond in JSON format.

Example Prompt:

Return the user's information in JSON.
Schema-Validated Structured Output

Schema validation defines the exact structure that the output must follow. Every field has a specified type, and required fields cannot be omitted.
